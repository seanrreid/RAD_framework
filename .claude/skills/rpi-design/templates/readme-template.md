## Information Flow

Tasks flow **down as scoped instructions** and return **up as compact summaries**.
Raw file contents never cross a boundary upward.

1. User sends task to **Parent Orchestrator**
2. Parent delegates to relevant **Role Orchestrators**
3. Role Orchestrators call **Context Tools** to gather facts
4. Context Tools return ≤15-line summaries
5. Role Orchestrators assemble summaries into domain plans
6. Parent Orchestrator assembles domain plans into a final implementation plan
7. Implementation runs in a fresh context seeded with the plan only

## Getting Started

1. Seed a session with `compaction-artifact.md`
2. Describe your task to the Parent Orchestrator
3. Let the orchestrator delegate — do not call context tools directly
4. Review the implementation plan before execution begins
5. Compact at phase transitions (Research → Plan, Plan → Implement)

---

## Adapting This Architecture

- Replace `tool.stub` files with your framework's file-reading implementation
- Adjust `scoped_to` paths in each `config.json` to match your actual directory structure
- Add new context tools under the appropriate orchestrator using `docs/adding-a-new-agent.md`
- Adjust `max_tokens` budgets based on your actual file sizes
