# Research Directory

Research artifacts live here. Created by `/rad-research`, consumed by `/rad-design`.

## Naming

```
[kebab-case-project-slug].md         ← research artifacts
```

## Status values

| Status | Meaning |
|--------|---------|
| `pending-design` | Research complete — ready for `/rad-design` |
| `in-progress` | `/rad-research` is still running |

## What goes here

Research artifacts capture what is being built, who is building it, and what
constraints shape the agent architecture. They are not plan files — they operate
at the project level, not the feature level.

One artifact per project. Re-run `/rad-research` to update it if the spec changes
significantly before `/rad-design` has run.
